
# NE555와 LTC1624 기반 Buck Converter 출력 특성 비교

## 1. 설계 목적

본 프로젝트의 목표는 자동차 또는 일반 DC 전원에서 공급되는 12V를 휴대폰 충전에 사용할 수 있는 안정적인 5V로 변환하는 Buck Converter를 LTspice로 설계하고 검증하는 것이다.

초기 회로에서는 NE555 타이머를 PWM 발생기로 사용하였다. 이를 통해 MOSFET의 스위칭과 Buck Converter의 기본 동작 원리를 확인할 수 있었지만, 기동 시 출력전압이 크게 상승하고 5V 부근에서 반복적으로 흔들리는 문제가 발생했다.

이 문제를 개선하기 위해 최종 회로에서는 Buck Converter 전용 컨트롤러인 LTC1624를 적용하였다.

이번 비교에서는 두 회로의 휴대폰 부하 측 출력전압을 확인하고 다음 특성을 분석하였다.

* 기동 시 최대 출력전압
* 출력전압 오버슈트
* 목표전압까지의 정착시간
* 정상상태 출력전압
* 출력전압의 진동 및 안정성
* 부하 변화에 대한 대응 가능성
* 인덕터 전류 제한 및 MOSFET 보호 기능

> 파형의 수치는 LTspice 화면을 기준으로 읽은 근사값이므로, 정확한 값은 커서 또는 `.meas` 명령을 이용해 확인해야 한다.

## 2. NE555를 먼저 사용한 이유

NE555는 비교적 간단하게 주기적인 펄스 신호를 만들 수 있는 타이머 IC이다. 외부 저항과 커패시터를 이용하면 발진 주파수와 듀티비를 조절할 수 있기 때문에 PWM과 Buck Converter의 기본 원리를 학습하기에 적합하다.

NE555를 이용한 초기 회로를 통해 다음 내용을 확인할 수 있었다.

* PWM 신호의 주파수와 듀티비 설정
* MOSFET의 ON/OFF 동작
* 인덕터의 에너지 저장과 방출
* 쇼트키 다이오드의 프리휠링 동작
* 출력 커패시터의 평활 작용
* 듀티비와 평균 출력전압의 관계
* 개방 루프 방식의 한계

이상적인 Buck Converter에서 입력전압과 출력전압의 관계는 다음과 같다.

```text
VOUT ≈ D × VIN
```

12V를 5V로 낮추기 위한 이상적인 듀티비는 다음과 같다.

```text
D ≈ VOUT / VIN
  ≈ 5V / 12V
  ≈ 0.417
  ≈ 41.7%
```

따라서 NE555의 PWM 듀티비를 약 41.7%로 설정하면 이론적으로는 약 5V가 출력되어야 한다.

하지만 실제 회로에는 MOSFET의 전압강하, 다이오드의 순방향 전압, 인덕터의 DCR, 커패시터의 ESR 및 부하 변화가 존재한다. 따라서 듀티비만 고정해서는 출력전압을 정확히 5V로 유지하기 어렵다.

이 과정을 통해 단순히 PWM을 생성하는 것과 출력전압을 안정적으로 제어하는 것은 서로 다른 문제라는 것을 확인했다.

## 3. NE555 기반 회로의 출력 파형

NE555 기반 회로에서는 출력전압이 0V에서 상승한 후 목표전압인 5V를 크게 초과했다.

파형에서 확인한 대략적인 변화는 다음과 같다.

```text
0V
→ 약 8.7V까지 상승
→ 약 4.8V까지 하강
→ 다시 약 5.3V까지 상승
→ 여러 번 진동
→ 최종적으로 약 5.1V 부근에 정착
```

### 3.1 기동 오버슈트

목표전압이 5V인데 기동 시 약 8.7V까지 상승했다.

오버슈트율은 다음과 같이 계산할 수 있다.

```text
오버슈트율
= (최대전압 - 목표전압) / 목표전압 × 100

= (8.7V - 5V) / 5V × 100
≈ 74%
```

최종적으로 출력이 5V 부근에 도달하더라도, 기동 과정에서 약 8.7V가 발생한다면 실제 휴대폰 충전 전원으로 사용하기 어렵다.

전원회로에서는 정상상태 출력전압뿐만 아니라 다음 항목도 함께 확인해야 한다.

* 전원 인가 순간의 최대전압
* 목표전압까지 도달하는 시간
* 전압이 반복적으로 흔들리는지 여부
* 부하가 변했을 때의 전압 하강과 회복
* 출력 커패시터와 인덕터에 흐르는 순간전류

### 3.2 링잉 현상

NE555 회로에서는 출력전압이 목표값에 바로 정착하지 않고 5V를 기준으로 위아래로 반복해서 흔들렸다.

이 현상을 링잉 또는 저감쇠 응답이라고 볼 수 있다.

```text
출력전압이 낮음
→ PWM 제어회로가 에너지 전달량을 증가
→ 인덕터 전류 증가
→ 출력 커패시터 충전
→ 출력전압이 5V를 초과
→ PWM 감소
→ 출력전압이 5V 아래로 하강
→ PWM 다시 증가
→ 반복적인 진동 발생
```

MOSFET을 끈 순간에도 인덕터에 저장된 에너지는 바로 사라지지 않는다. 인덕터는 기존 전류를 계속 유지하려고 하므로 쇼트키 다이오드를 통해 출력으로 에너지를 전달한다.

따라서 피드백 회로가 출력 과전압을 감지하고 PWM을 감소시키더라도 이미 인덕터에 저장된 에너지 때문에 출력전압이 계속 상승할 수 있다.

NE555는 기본적으로 타이머 IC이므로 이러한 인덕터 전류와 출력 LC 필터의 동작까지 고려한 제어 기능이 내장되어 있지 않다.

## 4. LTC1624 기반 회로의 출력 파형

LTC1624 회로에서는 출력전압이 약 0.7~0.8ms 동안 상승한 후 약 5.05V 부근에 정착했다.

대략적인 출력 변화는 다음과 같다.

```text
0V
→ 약 5.05V까지 부드럽게 상승
→ 큰 오버슈트 없이 목표전압에 도달
→ 정상상태에서 거의 일정하게 유지
```

NE555 회로에서 나타났던 약 8.7V의 기동 오버슈트가 사라졌으며, 5V 부근에서 반복적으로 나타났던 큰 진동도 거의 발생하지 않았다.

## 5. 두 회로의 파형 비교

| ------------------ | ------------------: | ---------------: |
| 목표 출력전압            |                  5V |               5V |
| 기동 시 최대전압          |              약 8.7V |           약 5.1V |
| 기동 오버슈트            |               약 74% |          약 2% 이내 |
| 5V 부근 정착시간         |             약 3~4ms |      약 0.7~0.8ms |
| 기동 후 진동            |             여러 번 발생 |            거의 없음 |
| 정상상태 출력전압          |              약 5.1V |          약 5.05V |
| 출력전압 제어            |           외부 회로에 의존 |       VFB 피드백 내장 |

| 상측 N-MOSFET 구동     |          별도 드라이버 필요 |  TG 및 BOOST 핀 제공 |

| 부하 변화 대응           |                 제한적 | 출력 피드백을 통해 자동 보정 |
| Buck Converter 적합성 |              원리 학습용 |    실제 폐루프 전압 제어용 |

현재 파형을 기준으로 LTC1624 회로는 NE555 회로보다 다음 특성이 개선되었다.

* 기동 오버슈트가 크게 감소했다.
* 목표전압까지의 정착시간이 짧아졌다.
* 출력전압의 반복적인 진동이 감소했다.
* 정상상태 전압 오차가 작아졌다.
* 출력전압이 5V 부근에서 안정적으로 유지되었다.

## 6. LTC1624가 더 안정적인 이유

### 6.1 출력전압을 지속적으로 확인한다

LTC1624는 VFB 핀을 통해 출력전압을 계속 확인한다.

VFB 핀에는 출력전압을 낮춰 전달하기 위한 저항분배기가 연결된다.

```text
VOUT ── R_TOP ──┬── VFB
                 │
              R_BOTTOM
                 │
                GND
```

LTC1624는 VFB 전압이 내부 기준전압인 약 1.19V가 되도록 MOSFET의 스위칭을 조절한다.

출력전압은 다음 식으로 설정된다.

```text
VOUT = 1.19V × (1 + R_TOP / R_BOTTOM)
```

출력전압이 목표값보다 낮아지면 다음과 같이 동작한다.

```text
VOUT 감소
→ VFB 감소
→ ITH/RUN의 전류 명령 증가
→ MOSFET을 통해 전달되는 에너지 증가
→ VOUT 회복
```

출력전압이 목표값보다 높아지면 반대로 동작한다.

```text
VOUT 증가
→ VFB 증가
→ ITH/RUN의 전류 명령 감소
→ MOSFET을 통해 전달되는 에너지 감소
→ VOUT 회복
```

NE555가 미리 정한 PWM을 출력하는 방식이라면, LTC1624는 실제 출력전압을 확인하면서 에너지 전달량을 자동으로 조절한다.

### 6.2 인덕터 피크전류를 매 스위칭 주기마다 확인한다

LTC1624는 VIN 핀과 SENSE− 핀 사이에 연결된 전류 감지 저항 `RSENSE`의 전압을 측정한다.

```text
VSENSE = V(VIN) - V(SENSE−)
```

전류 감지 저항에 흐르는 전류를 `IL`이라고 하면 다음 관계가 성립한다.

```text
VSENSE = IL × RSENSE
```

인덕터 전류가 설정된 피크값에 도달하면 LTC1624는 해당 스위칭 주기에서 MOSFET을 끈다.

```text
MOSFET ON
→ 인덕터 전류 증가
→ RSENSE 전압 증가
→ 설정된 피크전류에 도달
→ MOSFET OFF
```

이 기능을 통해 기동 시 출력전압이 낮더라도 인덕터 전류가 무제한으로 증가하는 것을 방지할 수 있다.

NE555 회로에서는 출력전압이 낮다는 이유로 MOSFET을 지나치게 오래 켜면 인덕터에 많은 에너지가 저장될 수 있다. 이후 MOSFET이 꺼져도 저장된 에너지가 출력으로 전달되면서 큰 오버슈트가 발생할 수 있다.

LTC1624는 인덕터 전류가 과도하게 증가하기 전에 MOSFET을 끄기 때문에 이러한 현상을 줄일 수 있다.

### 6.3 전류 모드 제어를 사용한다

LTC1624는 출력전압과 인덕터 전류를 함께 사용하는 전류 모드 제어 방식을 사용한다.

```text
외부 전압루프
→ 출력전압이 목표값인지 확인

내부 전류루프
→ 인덕터 전류가 허용값에 도달했는지 확인
```

출력전압만 확인하는 제어 방식은 출력전압이 실제로 변한 다음에야 반응할 수 있다.

반면 LTC1624는 인덕터 전류가 상승하는 과정에서도 상태를 확인한다. 따라서 출력 커패시터에 과도한 에너지가 전달되기 전에 MOSFET을 끌 수 있다.

이 내부 전류루프가 NE555 회로보다 빠르게 에너지 전달량을 제한할 수 있는 이유이다.

### 6.4 ITH/RUN 보상회로가 진동을 억제한다

Buck Converter의 출력단에는 인덕터와 커패시터가 연결되어 있다. 이 LC 필터는 특정 주파수에서 공진할 수 있으므로 피드백을 연결했다고 해서 항상 안정적인 것은 아니다.

제어기가 너무 빠르게 반응하면 출력전압이 반복적으로 흔들릴 수 있고, 너무 느리게 반응하면 부하 변화 후 전압을 회복하는 시간이 길어진다.

LTC1624의 ITH/RUN 핀에 연결된 저항과 커패시터는 제어루프의 응답속도와 안정성을 조절한다.

```text
보상이 부족함
→ 출력전압 진동
→ 큰 오버슈트 및 언더슈트 발생 가능

보상이 적절함
→ 목표전압에 빠르게 접근
→ 진동 감소
→ 안정적인 출력 유지
```

LTC1624 파형이 5V에 도달한 후 거의 수평으로 유지되는 것은 전류 모드 제어와 ITH/RUN 보상회로가 출력 LC 필터의 진동을 효과적으로 억제하고 있다는 의미이다.

### 6.5 상측 N채널 MOSFET을 직접 구동한다

Buck Converter의 상측에 N채널 MOSFET을 사용하려면 MOSFET의 Gate 전압이 Source 전압보다 높아야 한다.

```text
VGS = VGATE - VSOURCE
```

NE555의 출력은 GND 기준으로 동작하기 때문에 상측 N채널 MOSFET을 완전히 켜기 위해 별도의 하이사이드 게이트 드라이버가 필요할 수 있다.

LTC1624는 이를 위해 다음 핀을 제공한다.

* `TG`: 외부 상측 N채널 MOSFET의 Gate 구동
* `BOOST`: 부트스트랩 게이트 구동 전원
* `SW`: MOSFET Source 기준이 되는 스위칭 노드

TG는 GND 기준의 단순한 PWM 신호가 아니라 SW 노드를 기준으로 동작하는 부유형 게이트 신호이다.

따라서 실제 MOSFET의 Gate-Source 전압을 확인할 때는 다음 파형을 측정해야 한다.

```text
V(TG, SW)
```

`V(TG)`만 측정하면 GND 기준의 게이트 전압만 확인하게 되므로 MOSFET이 실제로 완전히 켜졌는지를 정확히 판단하기 어렵다.

## 7. LTC1624를 최종 컨트롤러로 선정한 이유

LTC1624를 선택한 이유는 단순히 NE555보다 출력 파형이 매끄럽기 때문만은 아니다. 12V에서 5V로 변환하는 Buck Converter에 필요한 주요 제어 기능이 하나의 구조 안에 포함되어 있기 때문이다.

### 7.1 12V 입력 조건에 적합하다

LTC1624의 입력 동작 범위는 약 3.5V~36V이다.

따라서 본 프로젝트의 12V 입력 조건을 충분히 만족하며, 향후 입력전압 변동에 대한 시뮬레이션도 진행할 수 있다.

### 7.2 Buck Converter 전용 폐루프 제어가 가능하다

NE555의 기본 목적은 타이머와 펄스 생성이다. 반면 LTC1624는 출력전압을 일정하게 유지하기 위한 스위칭 레귤레이터 컨트롤러이다.

LTC1624는 다음 정보를 바탕으로 MOSFET을 제어한다.

```text
출력전압 피드백
+ 인덕터 피크전류
+ 내부 기준전압
+ 제어루프 보상값
```

따라서 입력전압이나 부하전류가 변하더라도 출력전압을 목표값으로 복구할 수 있다.

### 7.3 인덕터 전류 제한 기능을 구성할 수 있다

LTC1624는 외부 전류 감지 저항을 통해 인덕터 피크전류를 확인한다.

데이터시트의 초기 설계 관계는 다음과 같이 사용할 수 있다.

```text
RSENSE ≈ 0.1V / IOUT(MAX)
```

예를 들어 최대 출력전류를 1A로 설계한다면 초기 검토값은 다음과 같다.

```text
RSENSE ≈ 0.1V / 1A
       ≈ 0.1Ω
```

이는 단순히 출력전압을 유지하는 것뿐만 아니라 MOSFET, 인덕터, 다이오드 및 부하에 과도한 전류가 흐르는 것을 제한하는 데 도움을 준다.

### 7.4 외부 MOSFET을 사용할 수 있다

LTC1624에는 파워 MOSFET이 내장되어 있지 않으며 외부 N채널 MOSFET을 사용한다.

외부 MOSFET을 사용하면 다음 항목을 직접 고려할 수 있다.

* MOSFET의 정격전압 `VDS`
* 허용 드레인전류 `ID`
* 도통저항 `RDS(on)`
* Gate Charge
* 도통손실
* 스위칭손실
* 접합온도
* 방열 조건

이는 회로 동작뿐만 아니라 전력반도체의 손실과 열 특성을 함께 분석하려는 프로젝트 방향에 적합하다.

MOSFET의 도통손실은 대략 다음 관계로 분석할 수 있다.

```text
PCOND ≈ IRMS² × RDS(on)
```

스위칭손실은 간단히 다음과 같은 형태로 검토할 수 있다.

```text
PSW ≈ 0.5 × VDS × ID × (tr + tf) × fSW
```

따라서 LTC1624 기반 회로는 향후 MOSFET 선정, 효율 비교 및 열 해석으로 프로젝트를 확장하기에 유리하다.

### 7.5 상측 N채널 MOSFET 구동 기능이 제공된다

LTC1624는 TG, BOOST 및 SW 핀을 이용해 상측 N채널 MOSFET을 구동할 수 있다.

NE555 기반 회로에서 별도로 해결해야 했던 하이사이드 게이트 구동 문제를 전용 컨트롤러 구조 안에서 해결할 수 있다는 장점이 있다.

### 7.6 고정된 200kHz 스위칭 주파수를 사용한다

LTC1624는 약 200kHz의 고정 스위칭 주파수로 동작한다.

한 스위칭 주기는 다음과 같다.

```text
T = 1 / f

T = 1 / 200kHz
  = 5µs
```

NE555처럼 외부 발진 저항과 커패시터의 오차에 따라 주파수가 크게 달라지는 문제가 줄어든다.

또한 스위칭 주파수가 정해져 있기 때문에 인덕터와 출력 커패시터를 선정하고 리플전류를 분석하기가 비교적 명확하다.

### 7.7 LTspice에서 동작을 상세하게 검증할 수 있다

LTC1624 기반 회로에서는 다음 파형을 각각 확인할 수 있다.

* 출력전압 `V(phone)`
* MOSFET의 실제 Gate-Source 전압 `V(TG, SW)`
* 스위칭 노드 전압 `V(SW)`
* 인덕터 전류 `I(L)`
* 전류 감지 저항의 전압
* 출력 커패시터 전류
* 부하전류
* 피드백 핀 전압 `V(VFB)`
* 제어 명령 전압 `V(ITH)`

이를 통해 단순히 5V가 출력되는지만 확인하는 것이 아니라, 컨버터 내부의 전압 및 전류 변화까지 분석할 수 있다.

## 9. 파란색 전류 파형 해석 시 주의사항

LTC1624 시뮬레이션의 파란색 파형이 `I(CPHONE)`이라면 이는 휴대폰이 소비하는 전류가 아니라 출력 커패시터 `CPHONE`에 흐르는 전류이다.

출력 커패시터는 스위칭 과정에서 반복적으로 충전과 방전을 수행한다.

```text
커패시터 충전
→ 한 방향의 전류

커패시터 방전
→ 반대 방향의 전류
```

LTC1624의 스위칭 주파수가 200kHz이면 한 주기는 5µs이다.

```text
T = 1 / 200kHz
  = 5µs
```

6ms 동안에는 약 1,200번의 스위칭이 발생한다.

```text
스위칭 횟수
= 6ms / 5µs
≈ 1,200회
```

따라서 전체 시뮬레이션 구간을 한 화면에 표시하면 각각의 펄스가 구분되지 않고 두꺼운 띠처럼 보일 수 있다. 이것만으로 회로가 불안정하다고 판단해서는 안 된다.

휴대폰 부하를 저항으로 모델링했다면 실제 부하전류는 다음 파형으로 확인해야 한다.

```text
I(RPHONE)
```

출력 커패시터의 리플전류를 자세히 확인하려면 정상상태의 마지막 50~100µs 구간을 확대해서 관찰해야 한다.

## 10. 출력전압 안정성을 수치로 비교하는 방법

파형을 눈으로 비교하는 것만으로도 LTC1624가 더 안정적이라는 사실을 확인할 수 있지만, 포트폴리오에서는 측정값을 함께 제시하는 것이 더 객관적이다.

LTspice 회로에 다음 측정문을 추가할 수 있다.

```text
.meas tran VOUT_MAX MAX V(phone) FROM 0 TO 5m
.meas tran VOUT_MIN MIN V(phone) FROM 0 TO 5m
.meas tran VOUT_AVG AVG V(phone) FROM 4m TO 5m
.meas tran VOUT_PP PP V(phone) FROM 4m TO 5m
.meas tran VOUT_RMS RMS V(phone) FROM 4m TO 5m
```

각 측정값의 의미는 다음과 같다.

| 측정 항목      | 의미                         |
| ---------- | -------------------------- |
| `VOUT_MAX` | 기동을 포함한 최대 출력전압            |
| `VOUT_MIN` | 지정 구간의 최소 출력전압             |
| `VOUT_AVG` | 정상상태 평균 출력전압               |
| `VOUT_PP`  | 정상상태 출력 리플의 Peak-to-Peak 값 |
| `VOUT_RMS` | 출력전압의 RMS 값                |

오버슈트율은 다음과 같이 자동 측정할 수도 있다.

```text
.meas tran OVERSHOOT PARAM (VOUT_MAX-5)/5*100
```

두 회로에서 동일한 측정문을 사용하면 다음 내용을 수치로 비교할 수 있다.

* 어느 회로의 최대전압이 더 낮은가
* 어느 회로가 5V에 더 가깝게 출력되는가
* 어느 회로의 정상상태 리플이 더 작은가
* 어느 회로가 목표전압에 더 빠르게 정착하는가

## 11. 공정한 비교를 위한 조건

NE555와 LTC1624의 성능을 정확하게 비교하려면 가능한 한 전력단 조건을 동일하게 설정해야 한다.

* 입력전압
* MOSFET 모델
* 인덕터 용량과 DCR
* 쇼트키 다이오드 모델
* 출력 커패시터 용량과 ESR
* 부하저항
* 시뮬레이션 시간
* 최대 시간 간격
* 초기조건
* 출력전압 측정 위치

특히 출력 커패시터의 용량이나 부하저항이 서로 다르면 정착시간과 오버슈트가 달라질 수 있다.

따라서 이번 파형은 각 회로의 전체적인 제어 특성을 비교하는 자료로 사용하고, 최종 성능 비교에서는 동일한 전력단 조건으로 다시 측정할 예정이다.

## 12. NE555와 LTC1624의 핵심 차이

### NE555 방식

```text
미리 설정한 PWM
→ MOSFET 스위칭
→ 인덕터에 에너지 저장
→ 출력전압 생성
```

출력전압이 변해도 기본적인 NE555 회로에서는 듀티비가 자동으로 수정되지 않는다.

외부 피드백을 추가할 수는 있지만, 다음 기능을 별도로 설계해야 한다.

* 출력전압 오차증폭
* 제어루프 보상
* 인덕터 전류 감지
* 과전류 제한
* 상측 MOSFET 게이트 구동
* Soft Start
* 단락 보호

### LTC1624 방식

```text
출력전압 측정
→ 목표전압과 비교
→ 허용 인덕터 피크전류 조절
→ MOSFET 스위칭 시간 조절
→ 출력에 전달되는 에너지 조절
→ 출력전압 복구
```

LTC1624는 단순히 더 정확한 PWM을 출력하는 IC가 아니다.

출력전압과 인덕터 전류를 함께 확인하면서 MOSFET을 제어하는 전용 스위칭 레귤레이터 컨트롤러이다.

따라서 NE555에서 LTC1624로 변경한 것은 타이머 IC를 다른 PWM IC로 교체한 것이 아니라, 개방 루프 PWM 회로를 폐루프 전력변환 시스템으로 발전시킨 것이다.

## 13. 프로젝트를 통해 확인한 내용

이번 비교를 통해 정상상태에서 5V가 출력된다는 사실만으로는 Buck Converter의 안정성을 판단할 수 없다는 것을 확인했다.

NE555 회로도 일정 시간이 지나면 약 5V에 도달했지만, 기동 시 약 8.7V의 오버슈트와 반복적인 출력 진동이 발생했다.

반면 LTC1624 회로는 다음과 같은 개선된 특성을 보였다.

* 기동 시 출력전압이 목표값을 크게 초과하지 않았다.
* 약 0.7~0.8ms 안에 5V 부근으로 정착했다.
* 정착 후 출력전압의 반복적인 진동이 거의 없었다.
* VFB를 이용해 출력전압을 지속적으로 확인했다.
* RSENSE를 이용해 인덕터 피크전류를 제한했다.
* 전류 모드 제어를 통해 매 스위칭 주기의 에너지 전달량을 조절했다.
* ITH/RUN 보상회로를 통해 LC 필터의 진동을 억제했다.
* TG와 BOOST 핀을 통해 상측 N채널 MOSFET을 적절하게 구동했다.

## 14. 최종 결론

NE555는 PWM과 Buck Converter의 기본 동작을 이해하기 위한 교육용 회로로 유용했다. 특히 고정 듀티비만으로는 실제 출력전압을 안정적으로 유지하기 어렵다는 사실을 직접 확인할 수 있었다.

그러나 휴대폰 충전용 전원에서는 정상상태 전압뿐만 아니라 기동 오버슈트, 출력 리플, 부하 과도응답 및 과전류 보호까지 고려해야 한다.

LTC1624는 다음 기능을 하나의 제어 구조 안에서 제공한다.

```text
출력전압 피드백
+ 인덕터 전류 감지
+ 피크전류 제한
+ 전류 모드 제어
+ 상측 N-MOSFET 구동
+ 제어루프 보상
+ Shutdown 및 Soft Start
```

실제 시뮬레이션에서도 LTC1624 회로는 NE555 회로보다 기동 오버슈트가 작고, 목표전압에 더 빠르게 도달했으며, 정상상태에서 출력전압을 안정적으로 유지했다.

따라서 본 프로젝트에서는 12V를 안정적인 5V로 변환하기 위한 최종 Buck Converter 컨트롤러로 LTC1624를 선정하였다.

이번 설계 변경은 단순한 부품 교체가 아니라 다음과 같은 설계 발전 과정으로 정리할 수 있다.

```text
NE555를 이용한 PWM 및 Buck Converter 원리 학습
→ 기동 오버슈트와 출력 진동 문제 확인
→ 고정 듀티비 제어의 한계 분석
→ 출력전압 피드백과 전류 제한의 필요성 확인
→ LTC1624 기반 전류 모드 폐루프 제어 적용
→ 안정적인 5V 출력 확인
```

이를 통해 Buck Converter에서는 MOSFET을 빠르게 스위칭하는 것뿐만 아니라 출력전압 피드백, 인덕터 전류 제어, 보상회로, 전력반도체 손실 및 보호 기능을 종합적으로 고려해야 한다는 것을 학습했다.
